# Bundled preview fonts

Unmodified fonts from the Google Fonts CSS API, downloaded 2026-10-10.
Families: Fredoka (400, 500, 600), Parkinsans (400, 500, 600, 700), Mochiy Pop One (400).
Local fonts.css preserves upstream weight declarations. No runtime font CDN is needed.
The accompanying OFL files are the upstream licenses from google/fonts/ofl.

Source CSS: https://fonts.googleapis.com/css2?family=Fredoka:wght@400;500;600&family=Mochiy+Pop+One&family=Parkinsans:wght@400;500;600;700&display=swap
